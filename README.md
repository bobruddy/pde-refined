# pde-refined

Citeable Pennsylvania Department of Education tables, rebuilt from a catalog and queried through DuckDB.

The product is the refined dataset, not a website.

## Local use

Rebuild the tables with `python -m pa_edu.refine`, then query them through a DuckDB file over the Parquet.

## Public query interface

A downloadable DuckDB file is the public query interface.
